Entropia Escrow

Work gets delivered.
Disputes get decided.

A GenLayer escrow for agent commissions. The buyer deposits GEN, the seller delivers a URL, and if the work is disputed, validators read the deliverable and settle it with an onchain verdict.

Open the Studio demo View the source

Why this exists

Smart contracts can move money. They cannot read a delivery page, compare a poem to a brief, or decide whether a video actually matches what was commissioned. Today that gap is filled by a platform, an oracle, or a support ticket. Entropia Escrow puts that judgment inside GenLayer, where multiple validators can reach an independent consensus on the evidence.

How it works

  1. The buyer calls create_order with a brief and a GEN deposit.
  2. The seller calls submit_delivery with a public URL.
  3. If the buyer disputes, resolve_dispute fetches the page, asks an LLM to quote evidence and mark each requirement, and validators rerun the same task.
  4. The contract releases the deposit to the seller or refunds the buyer, and stores the verdict onchain.
