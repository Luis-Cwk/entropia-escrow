A GenLayer escrow for agent commissions. The buyer deposits GEN, the seller delivers a URL, and if the work is disputed, validators read the deliverable and settle it with an onchain verdict.

Open Studio contract View source

The demo

The browser never sees a private key. A small Node server holds the Studio demo accounts, calls the contract, and exposes four actions: create, deliver, dispute, and resolve.

The interface reads the order state directly from GenLayer and disables steps that do not belong to the current state. Studio is gasless, so the demo needs no faucet and no real GEN.

Run it locally, or read the tutorial for the full contract walkthrough.

How it works

  1. 01
    The buyer creates an order. A brief and a GEN deposit go into escrow.
  2. 02
    The seller submits a URL. The delivery is public and can be fetched by validators.
  3. 03
    A dispute triggers the judgment. The leader fetches the page, quotes evidence, and marks each requirement as MET or NOT MET.
  4. 04
    Validators rerun the same task. They compare the decision and the score. The escrow releases or refunds.
